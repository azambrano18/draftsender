🚀 ¿Cómo usar DraftSender?
───────────────────────────────────────────────
1. Descomprime todo antes de usar.

2. **Abrir Outlook** antes de ejecutar DraftSender.

3. **Haz doble clic** en `DraftSender.exe`.

4. En la aplicación:
   - Selecciona una cuenta de correo Outlook.
   - Carga el archivo Excel con los datos de destinatarios.
   - Carga el archivo Word (.docx) con el cuerpo del mensaje.
   - Haz clic en **"Crear Borradores"** para generarlos.
   - Luego puedes usar **"Enviar Borradores"** para enviar automáticamente desde 1 a 3 cuentas con intervalos.

───────────────────────────────────────────────
📁 ¿Qué archivos necesitas tener a mano?
───────────────────────────────────────────────

📊 Excel: "formato.xlsm" con columnas `Correo`, `Asunto`, `Nombre`, `Empresa`, `Disponibilidad`.
📝 Word: Plantilla con textos_mail que puede incluir variables como [Nombre], [Correo], [Empresa], [Disponibilidad].

───────────────────────────────────────────────
🛠 Preguntas Frecuentes
───────────────────────────────────────────────

❓ No abre el programa  
✔️ Asegúrate de tener Outlook instalado y funcionando. Ejecuta como administrador si es necesario.

❓ ¿Puedo cerrar Outlook mientras envío?  
🚫 NO. Outlook debe permanecer abierto durante todo el proceso.

❓ ¿Cómo actualizo la aplicación?  
Haz clic en “Archivo > Actualizar” dentro del menú del programa.
