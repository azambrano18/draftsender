==============================
Guía rápida - DraftSender App
==============================

1. IDENTIFICACIÓN DE USUARIO
------------------------------
Al iniciar la aplicación por primera vez, deberás ingresar tu nombre. Esto permitirá personalizar la experiencia y registrar tu actividad.

2. CREACIÓN DE BORRADORES
------------------------------
a. Selecciona el perfil de Outlook y una cuenta vinculada.
b. Elige el método de creación:
   - Envíos 1: Para primeros contactos.
   - Seguimiento: Para responder correos anteriores.
c. Carga el archivo Excel (lista de destinatarios) y el archivo Word (contenido del mensaje).
d. Haz clic en "Crear Borradores". El sistema mostrará el avance.

3. ENVÍO AUTOMATIZADO
------------------------------
a. Haz clic en "Enviar Borradores".
b. Selecciona hasta 3 cuentas Outlook para enviar por intervalos.
c. Define un intervalo de envío por cuenta (30, 60 o 90 segundos).
d. Inicia el envío para cada cuenta de forma individual.

4. BUENAS PRÁCTICAS
------------------------------
✓ Asegúrate de tener Outlook abierto antes de crear o enviar correos.
✓ Revisa los campos obligatorios en tus archivos.
✓ No cierres la app mientras se crean o envían borradores.
✓ Usa intervalos de envío moderados para evitar restricciones de Outlook.
